### Featured Projects

#### 🤖 [Real-Time Person Detector](https://github.com)
*   **The Origin Story:** I engineered this custom "Ring-style" camera node during the 2026 UCSD Summer Engineering Institute (SEI) as a defensive counter-measure to track targets and avoid elimination in a high-stakes campus "Senior Assassin" game.
*   **Synopsis:** A lightweight computer vision application that processes live video streams to isolate human targets and push real-time alerts to a laptop terminal.
*   **A Challenge Overcame:** I didn't want the tracking locked to my laptop's built-in webcam. As the project scope grew, I used it as an opportunity to learn how software communicates across networks for the first time—successfully routing a live wireless feed from my phone over local Wi-Fi directly into the YOLOv8 inference loop, triggering an asynchronous auditory beep upon detection.
*   **Tech used:** Python, YOLOv8, OpenCV, Multithreading, IP Networking
*   👉 **[Explore the source code](https://github.com)**

#### ♟️ [MiniMax Backgammon AI](https://github.com)
*   **Synopsis:** A game engine that calculates complete legal move matrices based on dice rolls and evaluates optimal paths to play intelligently against human opponents.
*   **A Challenge Overcame:** Backgammon state spaces can explode exponentially—especially during rare dice states (like rolling four combinations of 1s). Designing a system to handle this without choking performance was tough. I implemented Minimax with Alpha-Beta pruning to aggressively cut out unviable paths, and then systematically profiled my runtime execution efficiency to dramatically compress decision wait times.
*   **Tech used:** Python, PyCharm, Algorithmic Heuristics, Profiling
*   👉 **[Explore the source code](https://github.com)**

#### ⚔️ [Dominate or Decease](https://github.com)
*   **Synopsis:** A turn-based tactical board game inspired by D&D. Managing 9 completely unique character classes with active status effects required a heavily modular object-oriented architecture. I designed the core state machines tracking turn conditions, character ranges, abilities, unique attacks, and token-collection tracking for "super" moves.
*   **A Challenge Overcame:** Acted as Project Lead for a 4-person development pipeline. The hardest constraint was managing feature creep and handling complex state synchronization across multiple developers' code. I enforced code modularity and structural patterns so individual class abilities could interact cleanly without breaking the main game engine thread.
*   **Tech used:** Java, IntelliJ, OOP Architecture, Git Collaboration
*   👉 **[Explore the source code](https://github.com)**
